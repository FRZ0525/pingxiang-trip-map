- 包含萍乡周边景点（武功山、安源、杨岐山）与 Day1–Day3 行程；返程改为经花山回杭州
- 图层按段分组，可单独勾选；支持测距、搜索、全屏、小地图
- **⚡充电规划**（新）：12 条路线每条都列出沿线 OSM 服务区/停车区/充电站候选点；可设续航、出发电量、每站充至、预警阈值，勾选充电点后自动算每段到达电量（低于预警标红、到不了标深红）；“自动推荐”给出次数最少的方案；地图上点击候选点可选择，并可一键用高德/百度导航。选择保存在本机浏览器。手机上面板为底部抽屉。
- **🧭 自定义路线**（新）：任意起点/终点，可加途经点（↑↓ 排序）、地图点选（标记可拖动）、“我的位置”；数据源可切换 **高德 / 百度 / 开源（OSM）/ 对比**（对比模式同时计算所有可用来源：高德实线、百度点划线、开源虚线并列比较）。每条方案可直接进入“⚡充电规划”，候选点可合并高德 POI、百度 POI 与 OSM（约 200 m 去重，逐条标注来源）。最近路线保存在本机，可生成分享链接（`?from=纬度,经度&to=…&via=…`，打开即自动规划）。
  - 开源：OSRM 路线（router.project-osrm.org，备用 routing.openstreetmap.de）、Photon 联想 + Nominatim 搜索、OSM 候选点（页面内置浙赣湘粤闽快照，范围外实时查询 Overpass）。免费、无需 Key。
  - 高德：已在 index.html 顶部 `window.PXMAP_AMAP` 配置 Web端（JS API）Key，默认使用高德；也可在页面“自定义 → ⚙ 高德 Key 设置”换成自己的 Key（仅存本机浏览器）。高德不可用时自动改用开源数据。路线策略：推荐（多方案）/ 高速优先 / 避免收费；高速外充电站数量过多时默认隐藏。
  - 百度：`window.PXMAP_BAIDU` 配置浏览器端 AK（JSAPI 3.0，Referer 白名单），路线策略：推荐 / 躲避拥堵 / 高速优先 / 避开高速（相同路线自动合并）；沿线“服务区”“充电站”周边检索（约每 16 km 一次）。百度 JSAPI 不提供路费；坐标 BD-09 自动换算为 WGS84。也可在“⚙ 高德 Key / 百度 AK 设置”中换成自己的 AK。
