# 杭州 → 萍乡 国庆自驾路线图（电车版）

在线地图：https://frz0525.github.io/pingxiang-trip-map/

- 出发日期：2026-09-30（国庆前一天）
- 推荐路线：沪昆高速 G60 全程，约 803.5 km，畅通驾驶约 9 小时 13 分，途中充电 2 次（三清山服务区约 324 km、南昌南服务区约 563 km）
